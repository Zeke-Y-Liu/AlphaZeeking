# T-L2 · draft→active 七重门禁（set_status 封闭实验）

## 目标
激活门禁固化：`set_status(draft→active)` 必须七重全过，CLI 强制、无旁路。

## 七重门禁
| # | 门禁 | 来源 | 口径 |
| --- | --- | --- | --- |
| ① | valid | M2/M3 | 因子可计算、截面覆盖达标、IC 时序存在 |
| ② | 时间稳健 | M4 ① | walk-forward 样本外衰减 < 50%；无单一年度贡献 > 50% |
| ②' | 参数稳健 | M4 ② | ±30% 网格方向不反转、IC_IR 漂移 < 40% |
| ②'' | 环境稳健 | M4 ③ | 牛熊分段失效环境标签可解释（软关：局部失效允许、登记） |
| ③ | 增量价值 | M4 ④ | 与全部 active 因子 |ρ| < 0.6 |
| ④ | 多重检验 | M4 ⑤ | 同批 ≥20 候选对最优者施加 Bonferroni/DSR（首批 <20 流程就绪即可） |
| ⑥ | hypothesis 不悬空 | R3 | hypothesis_id 必须指向存在的假设登记且未被证伪 |

## 核心交付
1. `set_status` 封闭：门禁判定全部读 M4 `fl_factor_gate` 落库结果（强依赖首次建立），不重复计算
2. 任一门禁未过 → 激活拒绝 + 逐项失败原因报告（可读、可定位）
3. 软关（环境稳健）与硬关区分：软关失败登记后允许带标签激活，硬关失败一律拒绝
4. 门禁重放：同一因子重复激活请求幂等（已过门禁不重复跑）
