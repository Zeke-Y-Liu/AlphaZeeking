## 已知口径与注意事项

1. **美股滞后一日**：US 市场 as_of 为上一交易日（收盘口径 + 时差），非缺陷。
2. **基金 K 线晚间发布**：ETF/LOF 当日 bar 可能夜间才到，calendar_check 对当日滞后自动豁免（历史日真缺失仍 FAIL）。
3. **MinIO 固定 9100**：沙箱 9000 被系统服务占用，已通过 `.env` 的 `AP_MINIO_ENDPOINT=localhost:9100` 修正；勿改回 9000。
4. **登录锁定测试放最后**：避免影响后续用例；解锁命令见 M0-5。
5. **同步互斥**：sync job 全局唯一，进行中再提交返回 409 属预期防护。
6. **价格为实时快照**：行情数值与本清单示例值存在盘面偏差属正常。
7. **日志定位**：core/bff/web 日志在 `/tmp/alphapocket-logs/`，异常时附对应日志尾部。
