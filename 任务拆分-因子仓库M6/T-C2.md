# T-C2 · 合成端：四法并列合成 + 双闸 + fl_composite_snapshot 落库

## 目标
新增 `composite.py`：对池内因子横截面做四法并列合成打分，双闸防过拟合，快照落库可追溯。

## 核心交付
1. **四法并列**（同一输入、四种权重、并列输出，不择优）：
   - `equal`：等权
   - `ic_12m`：滚动 12 个月 IC 加权（消费 M3 fl_factor_eval 的 IC 时序）
   - `ic_ir`：IC_IR 最大化权重
   - `lasso`：稀疏回归（Lasso）
2. **打分口径**（与 M1 合成打分一致）：`rank` 定向（`asc` 小值优 / `desc` 大值优）；缺失值按可用因子权重归一；截取中位百分位（pandas 口径）；Top-N 并列按 `seed` 序可复现
3. **双闸防过拟合**：
   - 闸一：四法结果两两 rank 相关 < 0.7 → 任一对低于阈值即「过拟合告警」（登记不阻断）
   - 闸二：相邻期权重变化 ≥ 30% → 「冻结复核」（本例不自动进入下一期，登记待人工复核）
4. **落库**：`fl_composite_snapshot`——每再平衡期的四法权重、截面得分、双闸状态、as_of、strategy_id、git sha 可追溯

## 契约要点
- 输入：T-C1 的 `StrategySpec` + M1 物化因子表（严格 `dt` = 观测日，绝不取未来截面）
- 输出：四法并列的截面得分矩阵 + 权重时序 + 闸状态；T-C3 撮合端任选其一方法或并列比较

## DoD 验收

- [ ] 真实数据：三策略 YAML 各跑通一次合成，四法并列输出
