## 3. 三项关键设计决策（旧会话已登记，执行时遵守）

1. **近似版策略如实披露**：三策略均以 active_pool 池内 3 因子（`mom_20d_fl` / `sig_mom20_rank_fl` / `val_pe_ttm`）联调；`qua_roe_ttm` 不在档。正式因子替换归 **M7**（替换清单：`low_vol_252d` / `div_payout_streak` / `gro_np_yoy`），三策略跑不通的如实登记失效清单，不得静默改入参配置
2. **单引擎先行**：backtrader / qlib 交叉核对归 M7 #10.2；M6 只做自研撮合引擎（约束撮合）
3. **L2 只做归因归位**：因子暴露先行、风格归因留钩子；universe 过滤数据源缺失一律 degraded 警示，不静默

## 4. Strategy DSL 契约（YAML 骨架）

```yaml
id: <kebab-case>            # 如 lowvol-dividend-v1（近似版）
universe: CN_EQUITY_NONST   # 三过滤器：flt_st + flt_listed_days + flt_avg_amount_20d
factors:
  - {id: mom_20d_fl,       weight: equal}      # 池准入：id 必须 ∈ active_pool
  - {id: sig_mom20_rank_fl, weight: ic_12m}    # 合成权重法可配
  - {id: val_pe_ttm,       weight: equal}
composite: {top_n: 50, method: [equal, ic_12m, ic_ir, lasso]}   # 四法并列
rebalance: monthly
exec: next_day_vwap
constraints: {max_weight: 0.05, min_history: 500d}
benchmark: CSI300_TR
```
