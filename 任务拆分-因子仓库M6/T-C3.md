# T-C3 · 撮合端：次日 VWAP + 成本表 + 约束撮合 + 无偷价审计

## 目标
扩展 factorlib 侧 `backtest.py`（或新增撮合模块）：策略层回测撮合引擎，P0 单引擎（自研约束撮合；backtrader/qlib 交叉归 M7 #10.2）。

## 核心交付
1. **成交价**：次日 VWAP（`amount/volume` 派生）；无 VWAP 时用次日均价并**标注**（不得静默替换）
2. **成本表**（表驱动可配）：佣金万 2.5（min ¥5）+ 印花税卖出 0.05% + 过户费 0.001% + 滑点 5bps
3. **约束**：T+1；涨跌停/一字板/停牌不可成交（顺延或跳过，可配）；100 股整数倍
4. **无偷价审计**：回测成交价全部 ≥ 次日价格区间校验（low ≤ fill ≤ high；缺 low/high 行返回 None 信任 VWAP——真实行情均带 OHLC，边界防御）；换手与再平衡频率匹配校验
5. **路径**：VWAP 自动路径 + 跨路径 cost 兼容（`net`/`gross` 双列，方向兼容：net 单调时 sharpe/calmar 为 None 的口径登记）
6. **缺省路径 bit 级对算**：缺省参数路径与既有 α 组合回测逐日用例 bit 级一致（不破坏锚点）

## 契约要点
- 输入：T-C2 合成得分（截面）+ M1 因子表 + 行情（OHLCV+amount）
- 输出：逐期成交明细（ledger 持久化）+ 持仓序列 + 成本分解；T-C5 报告端消费
- `_fill_price` 语义：行缺 low/high → None（无从校验可行域）；实现端不做空条件下过严的防御（旧会话修复 #1）
