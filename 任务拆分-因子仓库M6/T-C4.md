# T-C4 · 验证端：策略层 walk-forward + lockbox 一次性 + ±30% 敏感性网格

## 目标
新增 `strategy_wf.py`：策略级（非单因子级）样本外验证纪律，防过拟合三件套。

## 核心交付
1. **扩展窗口滚动 walk-forward**：`train_min_months / valid_months / step_months` 可配（与 M4 因子层协议同源，策略层重实现）；每折以折内数据合成权重、折外撮合回测
2. **lockbox 一次性验证**：2022-01 起封存区间，**只验证一次**（登记后不得因结果不佳重跑调参）；验证产物归档（`#1 归档×3`——三策略各一次）
3. **±30% 敏感性网格**：核心参数（`top_n` / `method` / 成本滑点等，具体集合以 T-C1 StrategySpec 实际字段为准）±30% 网格；门槛：策略排序稳定（`rank_stable=True`）、收益变化单调不翻转
4. **ledger 持久**：每折每参数组合的运行登记 ledger，可追溯、可复现（seed 冻结）

## 实测基准（旧会话）

- 滑点 0→10bps 策略排序稳定（收益变化单调、不翻转）——M6 DoD 第二项
